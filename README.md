This repository contains Java implementation of algorithms, that we usually find in any algorithms text book.

So far I have the following algorithms
1.  Bag implementation using link list
2.  Bag implementation using array resize 
3.  Stack implementation using link list
4.  Queue implementation using link list
5.  Min Priority Queue using binary heap
6.  Max Priority Queue using binary heap
7.  Heap sort
8.  Selection Sort
9.  Insertion Sort
10. Quick Sort
11. 3-Way Quick Sort
12. Binomial Heap

Also, worked on the following interview problems
1.  Merged K Sorted arrays using Priority Queue
2.  Merge 2 sorted Link list
